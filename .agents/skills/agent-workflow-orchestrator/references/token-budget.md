# Context and Token Conservation

Keep the coordinating agent's context for essential task ownership, plan, decisions, approvals and integration evidence. Read one canonical SKILL.md and only references needed for the current operation. Use small, self-contained worker packets, short handoffs and final focused checks rather than redundant full-suite or multi-model review rituals. Avoid passing unrelated repository history to every worker. A different agent session does not magically increase a shared provider quota pool; only use independently confirmed capacity.
